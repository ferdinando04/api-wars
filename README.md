# API WARS 2026

Proyecto del equipo para la hackathon API WARS (Universidad Distrital, Facultad Tecnológica + Factus), 05-oct-2026.

## Arrancar

1. Copiar `.env.example` a `.env` y pedir las credenciales **por privado** (nunca por el grupo ni en un commit).
2. Comprobar que funcionan: `python scripts/verificar_credenciales.py`
3. El enunciado del reto está en `RETO.md`; el código va en `app/`.

## Qué hay

- `docs/factus-api/` - colección Postman oficial de la API de Factus v2 y notas de los cambios v1 → v2.
- `docs/factus-pay/` - Factus Pay (cobro con QR Bre-B): documentación y análisis del sandbox.
- `referencias/` - código de referencia ya probado contra la API (solo lectura).
- `.claude/skills/` - guías para trabajar con Claude Code en este proyecto.
