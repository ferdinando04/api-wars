# Listar

Método:GET

#### Endpoint
• Sandbox
• Producción

• https://pay-api-sandbox.factus.com.co/v1/collections

https://pay-api.factus.com.co/v1/collections

Devuelve, paginados, los recaudos de tu empresa.

#### Encabezados de la solicitud
Ver encabezados requeridos
 | Authorization
: Bearer <tu-token>

Token de autenticación necesario para acceder al recurso. Consulta Autenticación para obtenerlo.
 | Accept
: application/json

Indica que la respuesta debe estar en formato JSON.

Nota: Reemplaza <tu-token>
 con el token obtenido tras autenticarte.

, rejected

 | reference_code
string
opcional

Filtra por código de referencia exacto. Máx. 100 caracteres.
