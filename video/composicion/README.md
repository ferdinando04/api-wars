# Composición del video pitch (Remotion)

Copia de `Desktop/proyecto-video-ai/src/firebox/` (ahí se renderiza, en la nube).

- `FireboxPitch.tsx`: cada escena muestra el código real, capturas y diapositivas en el segundo en que el narrador las nombra.
- `codigo.json`: los fragmentos REALES del repositorio (con su número de línea) y la salida real del control negativo, generados por `video/preparar_material.py`.
- Las voces (`voces.json` + audios) se generan con `video/preparar_voces.py` y no se suben (pesan y son de los integrantes).
